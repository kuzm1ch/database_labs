## Лабораторна робота №3 — індивідуальні варіанти

Четверте місто визначається за вашим номером у списку групи. До таблиці увійшли міста з населенням понад 50 тис. осіб (за [переписом 2001 року](https://uk.wikipedia.org/wiki/%D0%9C%D1%96%D1%81%D1%82%D0%B0_%D0%A3%D0%BA%D1%80%D0%B0%D1%97%D0%BD%D0%B8_(%D0%B7%D0%B0_%D0%B0%D0%BB%D1%84%D0%B0%D0%B2%D1%96%D1%82%D0%BE%D0%BC))) у алфавітному порядку, без Києва, Львова та Одеси, які є спільними для всіх.

### Правила

- ваш номер у списку групи = номер міста в таблиці; якщо номер більший за 35 — відніміть 35;
- у ключах Redis використовуйте назву з колонки «Назва для ключів» (латиниця, [офіційна транслітерація](https://zakon.rada.gov.ua/laws/show/55-2010-%D0%BF));
- у тексті лабораторної `<misto>` означає саме цю назву, наприклад `weather:vinnytsia:temperature`.

### Приклад

Студент з номером **11** у списку групи працює з містами: Київ, Львів, Одеса та **Вінниця**. Його ключі:

```console
HSET city:vinnytsia temperature 11 humidity 78
TS.CREATE weather:vinnytsia:temperature LABELS city vinnytsia metric temperature unit C
XADD traffic:events * city vinnytsia bytes 1830 status 200
```
